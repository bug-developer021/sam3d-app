# Best Practices for Photography

To ensure high-quality 3D models from your images, follow these guidelines when taking photos.

## 1. Lighting
- **Even Lighting**: Ensure the object is evenly lit. Avoid strong shadows or harsh highlights.
- **Diffuse Light**: Soft, diffuse light (like on a cloudy day or using a softbox) is best.
- **Avoid Reflections**: Highly reflective surfaces (mirrors, glass, shiny metal) are difficult to reconstruct. Try to minimize reflections or use a polarizing filter.

## 2. Background
- **Clean Background**: Use a plain, solid-colored background (white, grey, or black) that contrasts with the object.
- **Declutter**: Remove any unnecessary objects from the frame.
- **Separation**: Ensure there is some distance between the object and the background to avoid shadows casting on the background.

## 3. Camera Angles & Framing
- **Fill the Frame**: Get close enough so the object fills most of the frame, but keep the entire object visible.
- **Eye Level**: Start with shots at eye level with the object.
- **Multiple Angles (for Multi-view)**: If using multi-view reconstruction, take photos from different angles (front, side, top, 45-degree) ensuring overlap between views.

## 4. Object Characteristics
- **Texture**: Objects with rich textures (wood, stone, fabric) reconstruct better than featureless, smooth objects (plain plastic).
- **Stability**: Ensure the object does not move during photography.

## 5. Image Quality
- **Resolution**: Use the highest resolution available on your camera.
- **Focus**: Ensure the entire object is in sharp focus. Use a smaller aperture (higher f-number) if possible to increase depth of field.
- **Format**: Save images in high-quality formats like JPEG (high quality) or PNG. Avoid heavy compression.
